# 🔢 Streamlit 예외 처리 계산기

Streamlit을 활용하여 두 정수와 연산자를 입력받고 예외 처리가 포함된 계산기 애플리케이션입니다.

---

## 📌 주요 기능
- **직관적인 UI**: 정수 입력창 및 연산자 선택 기능 제공
- **사칙연산 지원**: 더하기(`+`), 뺄셈(`-`), 곱하기(`*`), 나누기(`/`)
- **예외 처리 기능**:
  - 숫자가 아닌 값(문자, 실수 등) 입력 시 경고 메시지 출력 (`ValueError`)
  - 0으로 나누기 시도 시 경고 메시지 출력 (`ZeroDivisionError`)

---

---

## 🚀 실행 방법

### 1. 필수 라이브러리 설치
터미널에서 아래 명령어를 실행하여 필요한 패키지를 설치합니다.

```bash
pip install -r requirements.txt
```

### 2. Streamlit 앱 실행
아래 명령어를 입력하여 계산기 앱을 실행합니다.

```bash
streamlit run app.py
```

명령어 실행 후 브라우저에서 자동으로 애플리케이션이 열립니다. (기본 주소: `http://localhost:8501`)
